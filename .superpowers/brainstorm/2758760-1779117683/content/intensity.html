How strong should the CRT effect be?

This determines whether it reads as "a window on a CRT" vs. "a stylized subtle filter"

A

Subtle (Modern Trinitron)

Light scanlines, mild curvature, very faint phosphor mask only visible at hi-res. Feels like a clean, high-end CRT monitor. Effect is barely noticeable in day-to-day use but adds warmth.

B

Balanced (Classic CRT monitor)

Noticeable scanlines, moderate barrel curvature, visible phosphor mask at 1x scale, subtle vignette. Reads clearly as a CRT. Like a good 90s CRT monitor.

C

Heavy (Arcade Cabinet)

Strong scanlines with dark gaps, pronounced curvature, chunky phosphor dots, heavy vignette, analog noise. Unapologetically retro. Like a CRT arcade screen.
