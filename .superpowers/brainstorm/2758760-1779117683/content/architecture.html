Pipeline Architecture

How should the CRT passes be structured?

Approach A: 2-pass (Recommended)
Pass 1: down0 — scale=0.5
  Kawase blur downscale
  (bloom source)

Pass 2: crt — scale=1.0
  Reads niri_input (original)
  Reads niri_mask (window bounds)
  All CRT effects in one pass:
  • Scanlines
  • Barrel curvature
  • Chromatic aberration
  • Phosphor bloom (from blur)
  • Phosphor mask pattern
  • Vignette
  • Noise

Simpler, faster. 1 blur pass.
Approach B: 3-pass
Pass 1: down0 — scale=0.5
  Kawase blur downscale

Pass 2: up0 — scale=2.0
  Kawase blur upscale
  (smoother bloom)

Pass 3: crt — scale=1.0
  Same CRT effects as A
  + mask distance awareness
  (edge effects like overshifted3)
A

2-pass (Recommended)

Simpler, faster, 40% fewer GPU passes. The CRT pass handles everything. Bloom uses a single kawase downscale — good enough for phosphor glow.

B

3-pass

Smoother bloom (down+up cascade), and CRT effects can vary by distance from window edge (stronger chromatic aberration at corners, etc). Costs an extra GPU pass.
